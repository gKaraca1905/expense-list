# Expense List

A small web app for tracking personal expenses. Built for the CMPS 510 final individual project (project #12).

**Live demo:** https://gkaraca1905.github.io/expense-list/

![Screenshot of the Expense List app](screenshot.png)

## What it does
- Add an expense with a name and an amount
- Shows the running total
- Delete an expense
- Saves the list in the browser (localStorage), so it stays after a page refresh
- Checks the input: empty names and amounts of 0 or less are rejected

## Built with
- HTML, CSS and plain JavaScript (no libraries, no server, no database)
- GitHub Pages for hosting

## Tools used
- VS Code and the Live Server extension for development
- GitHub and GitHub Pages for hosting
- Claude (AI assistant by Anthropic) helped me plan the project, write the code and explain how it works. I tested the app and I can explain the code.

## How to run locally
Download the files and open `index.html` in a browser.
